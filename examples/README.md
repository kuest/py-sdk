# Python examples

These imported scripts are migration references. Some still assume position-backed markets or realtime services that are not configured in this SDK. Do not use their trading or subscription flows with live services until each example is verified for the target operator.

For the supported read-only workflow, see the [workspace README](../README.md). Use a verified Deposit Wallet for orders and keep CLOB credentials separate from builder relayer credentials. The [SDK scope](../docs/sdk-direction.md) lists supported operations.
